Aliados · Credibanco — Secciones web

12 secciones Avada-ready. Haz clic en una tarjeta para previsualizar, luego copia code-block.html y styles.css en WordPress.

Cómo usar en Avada (3 pasos por sección):
1. Pega el contenido de code-block.html en un Code Block de Avada Builder.
2. Pega styles.css en Avada › Options › Custom CSS.
3. Si la sección tiene JS, pega script.js en Avada › Options › Custom JS.
4. Sube las imágenes de cada carpeta a Medios → WordPress y reemplaza las URLs marcadas con ← REEMPLAZAR.
